# Solver benchmark persistence amendment: 20 October 2026

Status: **implementation safeguard for a new, separate main-run attempt**. This record does not change the v4 study design, 21 inputs, comparator definitions, job schedule, search allowances, 135-minute runner ceiling, analysis rules, or scoring. The existing first main-run bundle remains an immutable stopped-run record.

The first v4 Windows main run stopped after 209 completed primary jobs when Python raised `PermissionError: [WinError 5] Access is denied` while replacing a JSON run record with its final version. The failure occurred at the file-replacement step after a worker had written a validation checkpoint. The available traceback does not establish which process held the file or whether the denial was transient. The 30/60-second comparisons and prototype checks were never started. See the [first-run manifest](../results/solver-selection-v4-21-events-135m-windows-main-2026-10-20/manifest.json) and [failing record](../results/solver-selection-v4-21-events-135m-windows-main-2026-10-20/runs/primary__full-accessible__two__cp_sat__5s.json).

The evidence writer now creates a unique temporary file in the destination directory, writes and flushes the complete JSON, and closes it before replacement. On Windows only, it retries replacement after bounded delays of 0.05, 0.1, 0.2, 0.4, 0.8, and 1.6 seconds when the reported Windows error is access denied (5), sharing violation (32), or lock violation (33). A successful replacement remains a single complete-record update. If the final attempt still fails, the error remains visible and the runner stops; the previous record is not silently counted as a completed observation. Temporary files are cleaned up when possible. The tests simulate transient and persistent denials and verify record integrity.

Use a new output directory for the second attempt, for example `docs/results/solver-selection-v4-21-events-135m-windows-main-attempt2-2026-10-20`. Do not resume the stopped bundle, merge its records into the new attempt, or overwrite its figures. The new manifest records the updated source hashes and this amendment. The operator should keep the result directory on a writable local drive and avoid opening live `runs/*.json` files with software that holds them open. A retry mitigates short-lived file locks; it does not repair persistent permissions or guarantee completion.
