## 1. Introduction

Software Requirements Engineering (SRE) is one of the most important phases in software development. Well-defined software requirements help ensure that a software system satisfies user needs and reduces the risk of project failure.

As part of your Final Year Project 1 (FYP1), you have prepared a project proposal that includes the background, objectives, and proposed solution. Before moving into the design and implementation phases, it is essential to review the quality of your proposed software requirements.

The purpose of this assignment is to identify strengths, weaknesses, and missing requirements, and to recommend improvements that will strengthen your FYP before entering the next development phase.

## 2. Assignment Objectives

Upon completion of this assignment, students should be able to:

1. Apply Software Requirements Engineering principles to evaluate an existing software proposal.
2. Identify functional and non-functional requirements in a software project.
3. Critically evaluate the quality of software requirements.
4. Recommend appropriate improvements based on Software Requirements Engineering principles.
